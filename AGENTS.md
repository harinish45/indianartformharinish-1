# AGENTS & Autonomous Tool Conventions

## Project Rules & Design Token Invariants

1. **Design System & Palette:**
   - Background: `--bg: #0e1016`, `--panel: #151926`.
   - Accents: Gold `--gold: #d9b36a`, Light Gold `--gold2: #f0d9a6`.
   - Text: Paper `--paper: #ece5d3`, Muted `--muted: #98a0b3`.
   - Fonts: Display `'Rozha One', Georgia, serif`, Body `'Work Sans', sans-serif`.

2. **Vanilla Architecture:**
   - Keep files self-contained and zero-dependency. Do not add heavy node bundlers unless requested.
   - Maintain semantic HTML5 structure with proper ARIA attributes.
